# Changelog

## 0.8 - 2026-05-19

Initial public release.

### Added

- GUI application: DJI GPX Extractor.
- DJI MP4/MOV telemetry extraction through ExifTool.
- GPX export.
- Language support:
  - English
  - Polish
  - German
  - Ukrainian
- Config persistence in `%APPDATA%\DJI_MP4_to_GPX\config.json`.
- Links to ExifTool, DJI Telemetry Overlay SRT Viewer, GPS Visualizer and Google Earth Web.
- Windows EXE metadata:
  - Product name: DJI GPX Extractor
  - Version: 0.8
  - Copyright: Adam Kucia
