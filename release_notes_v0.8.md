# DJI GPX Extractor v0.8

Initial public release.

## What it does

DJI GPX Extractor converts embedded DJI telemetry from MP4/MOV files into a GPX track.

## Requirements

- Windows
- ExifTool: https://exiftool.org/
- DJI MP4/MOV file with embedded telemetry metadata

## Download

Use the release asset:

```text
DJI_GPX_Extractor_v0.8_windows.exe
```

## Notes

This release does not include ExifTool. On first use, select your local `exiftool.exe` path in the application.
